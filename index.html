コメ欄 プライバシーポリシー

最終更新日：2026年9月7日／文書版：2026-09-07.2

「コメ欄」は、YouTube動画とコメントを同時に閲覧し、利用者が明示的に選択した場合にYouTube上の投稿・返信・高評価を補助するChrome拡張機能です。利用条件は利用規約に定めます。

インストール前に、Chrome Web Store掲載ページの重要事項と、リンク先の利用規約・本ポリシーをご確認ください。インストール後の独立した同意画面や確認タブは表示しません。新規インストールではONが既定で、YouTubeの通常動画ページを開くと以下の処理が始まります。インストールやリンクの閲覧を個別の同意として記録する仕組みはありません。利用を停止する場合は拡張ポップアップでOFFにするか、アンインストールしてください。Webサイトを配信するGitHub Pagesの接続情報の取り扱いは、後述の「このポリシーの公開サイトについて」をご確認ください。

端末内処理と利用目的

本ポリシーの「読み取り」「利用」「処理」「保存」は、特に記載がない限り、利用者の端末上で本拡張機能が行うことを意味します。本拡張機能からこれらの情報が開発者へ送信されることはなく、開発者が本拡張機能を通じて取得・閲覧する仕組みはありません。ただし、利用者自身がお問い合わせとして送信する情報は除きます。

ユーザーデータの利用は、Chrome Web Store User Data Policy（Limited Use要件を含みます）に従い、単一の目的であるYouTube動画とコメントの同時閲覧および利用者が明示的に選択したYouTube上の操作を提供・維持するために限定します。機能改善のための利用状況・操作ログの外部収集は行いません。

利用する情報

ONの場合、表示中のYouTube動画ページのDOM（画面を構成する情報）から、コメント本文、投稿者名、プロフィールURL・画像URL、投稿日、高評価数・自身の高評価状態、コメントID、親子関係、動画ID・タイトル・チャンネル名を読み取ります。再生状態・再生位置は自動スクロールと本文の時刻リンクに利用します。通常コメントの投稿時の動画再生位置を取得・推定するものではありません。

検索語、並び順、本文中の時刻、コメント・ファンの集計、処理元DOM、投稿・返信の下書きや処理状態はページ内のメモリで扱い、永続保存しません。コメント本文・投稿下書きをChromeのストレージへ保存しません。ページ再読み込み、動画ページからの移動、拡張機能OFFで表示用データと下書きを破棄します。

端末内に保存する項目

  • enabled：拡張機能のON/OFF設定。
  • commentFlowRoomsV1：動画IDをキーに、動画タイトル、チャンネル名、最終訪問日時、お気に入りコメントID、注目ファンの識別情報（投稿者URLまたは名前）、固定コメントID、選択タブ、互換用のフロー設定を保存します。
  • commentFlowRoomsEpochV1：ローカルデータ消去後に、古い保存要求で履歴が復活することを防ぐ管理用番号。
  • komeranConsentV1：旧版で保存した同意・不同意の状態等が残っている場合、過去の利用停止の選択を尊重するために読み取ります。新たな同意記録・同意日時は作成しません。ポップアップでON/OFFを明示的に変更すると旧記録を空にし、その設定を使用します。

保存先はChromeのローカルストレージです。最近のルームへの再訪、設定の復元に使用します。ルームは最大100件とし、超過時は最終訪問の古いものから削除します。その他は利用者による変更・消去またはアンインストールまで保存します。Chromeアカウント経由の同期は行いません。OFFまたは旧版で不同意を選択していた場合は自動で利用を開始せず、保存ルームも削除・初期化しません。

追加取得とYouTubeへの通常の通信

表示中の動画ページで、YouTube標準画面の追加読み込み・返信展開を利用してコメントを取得します。1回の取得は500件または60秒で一旦停止し、利用者が「取得を再開」を選ぶと続行します。「取得を停止」で途中停止できます。非表示タブ、全画面、投稿編集中は追加取得を休止します。開始済みのYouTube側の通信は取り消せない場合があります。他の動画を自動で開く、巡回する、非表示タブで新たに情報を収集する機能はありません。YouTubeが独自に行う通信は本拡張機能の制御対象外です。

プロフィール画像を表示すると、ブラウザがYouTubeページに記載されたHTTPSの画像配信元（yt数字.ggpht.com、yt数字.googleusercontent.com、lh数字.googleusercontent.com）へアクセスします。本拡張機能が作成する画像にはRefererを送信しない設定を使用しますが、配信元には通常の接続情報が伝わります。プロフィールリンクを押すとYouTubeのユーザーページが開きます。投稿者プロフィールを別途取得する機能はありません。

YouTubeへの公開・評価操作

本文は「投稿」「返信」またはCtrl/Cmd＋Enterによる明示的な送信操作時だけ、YouTube標準入力欄へ渡されます。「高評価」を押した場合もYouTube標準ボタンを操作します。ログイン中のYouTubeアカウントによる実際の公開・評価操作です。自動投稿、一括操作、送信結果不明時の自動再送は行いません。DOM上の反映確認は、YouTube側の永続保存やその後の審査・削除を保証するものではありません。

送信失敗・中断時は、本拡張機能がYouTube標準入力欄へ渡した未変更・未送信の本文だけを消去します。利用者が標準欄で編集した本文と、送信済みまたは結果不明の本文は誤削除を避けるため残します。YouTube標準画面で確認・管理してください。Cookie、パスワード、認証トークンを本拡張機能が読み取ることはありません。YouTubeでの取り扱いにはGoogleのプライバシーポリシー（外部サイト）が適用されます。

端末内データの削除・利用停止

端末内だけのデータには開発者がアクセスできず、遠隔で削除することもできません。ポップアップの「ローカルデータを消去」で、利用者自身が保存ルーム・お気に入り・固定・注目ファン・動画履歴を削除できます。OFFの場合も消去でき、ON/OFF設定と残存する旧版の記録は維持されます。アンインストールにより拡張機能のローカル保存データが削除されます。

ONの場合、消去後に別の動画を閲覧すると新たなルーム履歴が保存されます。保存したくない場合はOFFにしてください。ローカルデータ消去・OFFはYouTubeへ送信済みのコメントや高評価を削除する操作ではありません。

権限とシークレットモード

API権限は端末内保存用のstorageのみです。content scriptはhttps://www.youtube.com/配下で動作し、ONの場合に通常動画ページの読み取り・標準UI操作を行います。その他のサイトの履歴、Cookie、タブ一覧にはアクセスしません。シークレットモードでは実行できません。
