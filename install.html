コメ欄 ご利用案内

YouTube動画の右側でコメントを閲覧・検索・固定できます。インストールへ進む前に、利用条件とデータの取り扱いをご確認ください。

利用にあたって

  • コメントと投稿者情報を利用します。表示中の動画のコメント・返信・投稿者名・アイコン等を端末内で処理し、閲覧・検索・動画内のファン集計に使います。
  • 動画情報と設定をこの端末に保存します。最近の動画への再訪、お気に入り・固定等の復元に使います。コメント本文・投稿下書きは永続保存しません。
  • 開発者サーバーや広告・解析サービスへ送信しません。追加取得や画像表示ではYouTube側への通信が発生します。
  • 投稿・返信・高評価は実際の操作です。操作したときにログイン中のYouTubeアカウントへ反映されます。送信前に本文と対象を確認し、結果不明時はYouTube標準画面で確認してください。
  • コメント・返信を追加取得します。途中で停止でき、500件または60秒で一旦休止します。非表示タブ・全画面・投稿編集中も休止します。
  • 個人が無償で提供する非公式の拡張機能です。Google・YouTubeとは提携していません。仕様変更等で動作しなくなる場合があり、全件取得・継続提供は保証しません。

利用条件を確認する

利用規約（新しいタブ）には利用条件・免責事項・責任の範囲を、プライバシーポリシー（新しいタブ）には取得・保存する情報、通信、削除方法等を記載しています。

Chrome Web Store掲載ページ（外部サイト・新しいタブ）

この案内ページの経由は必須ではありません。インストール後に確認タブや独立した同意画面は表示しません。新規インストールではONが既定で、YouTubeの通常動画ページを開くとコメントの処理・動画情報の保存が始まります。既存タブは再読み込みしてください。インストールや文書の閲覧を個別の同意として記録する仕組みはありません。

利用停止はポップアップのOFFまたはアンインストールで行えます。過去のOFF・不同意は維持し、再開にはポップアップでONにする操作が必要です。保存データもポップアップから削除できます。このWebサイトの配信にはGitHub Pagesを利用しています。接続情報等の取り扱いはプライバシーポリシーをご確認ください。
